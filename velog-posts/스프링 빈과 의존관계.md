<h1 id="🫛spring-bean-등록-방법">🫛Spring Bean 등록 방법</h1>
<blockquote>
<p>Spring Bean: Spring Container가 관리하는 객체</p>
</blockquote>
<h2 id="1️⃣컴포넌트-스캔으로-자동-등록">1️⃣컴포넌트 스캔으로 자동 등록</h2>
<ul>
<li><code>@Component</code> 애노테이션이 있으면 스프링 빈으로 자동 등록된다.</li>
<li><code>@Component</code>를 포함하는 아래 애노테이션도 스프링 빈으로 자동 등록된다.<ul>
<li><code>@Controller</code></li>
<li><code>@Service</code></li>
<li><code>@Repository</code></li>
</ul>
</li>
</ul>
<h3 id="🔧서비스에-스프링-빈-등록">🔧서비스에 스프링 빈 등록</h3>
<pre><code class="language-java">@Service
public class MemberService {
  private final MemberRepository memberRepository;

  @Autowired
  public MemberService(MemberRepository memberRepository) {
    this.memberRepository = memberRepository;
  }
}</code></pre>
<ul>
<li>생성자에 <code>@Autowired</code> 를 사용하면 객체 생성 시점에 스프링 컨테이너에서 해당 스프링 빈을 찾아서 주입
한다. </li>
<li>생성자가 1개만 있으면 <code>@Autowired</code>는 생략할 수 있다.</li>
</ul>
<h3 id="🔧리포지토리에-스프링-빈-등록">🔧리포지토리에 스프링 빈 등록</h3>
<pre><code class="language-java">@Repository
public class MemoryMemberRepository implements MemberRepository {}</code></pre>
<ul>
<li>이제 <code>memberService</code> 와 <code>memberRepository</code> 가 스프링 컨테이너에 스프링 빈으로 등록되었다.</li>
</ul>
<h2 id="2️⃣java로-직접-등록">2️⃣Java로 직접 등록</h2>
<ul>
<li>서비스와 리포지토리에 <code>@Service</code>, <code>@Repository</code>를 추가하지 않고 <code>@Configuration</code>과 <code>@Bean</code>을 사용해 직접 등록하는 방법이다.</li>
<li>DI(Dependency Injection)에는 생성자 주입, 필드 주입, setter 주입이 있다. 의존 관계가 실행중에 동적으로 변하는 경우는 없으므로 생성자 주입을 권장한다.<h3 id="🧩생성자-주입">🧩생성자 주입</h3>
<pre><code class="language-java">@Configuration
public class SpringConfig {
@Bean
public MemberService memberService() {
  return new MemberService(memberRepository());
}
@Bean
public MemberRepository memberRepository() {
  return new MemoryMemberRepository();
}
}</code></pre>
<h3 id="🧩필드-주입">🧩필드 주입</h3>
<pre><code class="language-java">@Controller
public class MemberController {
  @Autowired private MemberService memberService;
}</code></pre>
</li>
</ul>
<h3 id="🧩setter-주입">🧩setter 주입</h3>
<pre><code class="language-java">@Controller
public class MemberController {
    private MemberService memberService;

    @Autowired
    public void setMemberService(MemberService memberService) {
        this.memberService = memberService;
    }
}
</code></pre>
<h3 id="❗주의">❗주의</h3>
<blockquote>
<p><code>@Autowired</code>를 통한 DI는 스프링이 관리하는 객체
에서만 동작한다. 스프링 빈으로 등록하지 않고 내가 직접 생성한 객체에서는 동작하지 않는다.</p>
</blockquote>
